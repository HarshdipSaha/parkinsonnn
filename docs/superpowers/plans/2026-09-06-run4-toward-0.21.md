```python
def to_3d_crop(x: torch.Tensor, crop=(48, 48, 32), center=None) -> torch.Tensor:
    """[B,1,X,Y,Z] -> [B,1,*crop]: axis-aligned crop centred on `center` (voxel coords; default box centre), clamped to the box."""
    B, _, X, Y, Z = x.shape
    c = [(X - 1) / 2, (Y - 1) / 2, (Z - 1) / 2] if center is None else list(center)
    sl = []
    for dim, (n, k, cc) in enumerate(zip((X, Y, Z), crop, c)):
        a = int(round(cc - k / 2 + 0.5)); a = max(0, min(a, n - k)); sl.append(slice(a, a + k))
    return x[:, :, sl[0], sl[1], sl[2]]
```

`datsc/train_v3.py` `InputSpec`: add fields `crop3d: tuple | None = None`, `center3d: tuple | None = None` (coerce lists to tuples in `__post_init__` if the class is a dataclass, else in `__init__`); `__call__` for 3D: `if self.crop3d: x = to_3d_crop(x, self.crop3d, self.center3d)` before `to_3d_input(x, self.size)`; `to_dict` adds `crop3d=list(...) or None, center3d=list(...) or None`.

`scripts/train_v3.py`: `--crop3d` (3 ints, optional), `--center3d` (3 floats, optional); `spec = InputSpec("3d", size=a.size, crop3d=..., center3d=...)`; tag `r3d_crop{'x'.join(crop3d)}_f…_s…` when `--crop3d` is set.
