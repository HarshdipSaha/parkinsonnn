# Inception: DaT Parkinson's Challenge (brownfield baseline)

Created 2026-09-06 by reverse-engineering the repository. Depth: minimal.

## Problem

DrivenData competition #311. Classify 3D DaT-SPECT NIfTI brain volumes as normal or abnormal (`is_pathologic` probability), scored by log loss on a hidden multi-centre test set. Code-execution competition: a `submission.zip` with `main.py` runs offline on 1x A100 within 3 hours, no internet. Deadline 2026-09-16 23:59 UTC. Full rules: `DAT_PARKINSONS_CHALLENGE.md`.

## Requirements

| Id | Requirement |
|---|---|
| R1 | `main.py` always leaves a valid `submission.csv` (`uid`, `is_pathologic`): prior written first, stage-wise overwrites, hard `os._exit(0)`. |
| R2 | Every test scan is processed independently; no pseudo-labelling; no statistics across test samples. |
| R3 | Only public, commercial-use external weights (torchvision ImageNet, BSD-3, accepted; DINOv3 and non-commercial weights excluded); disclose all. |
| R4 | One preprocessing code path for training and inference (`datsc/volume.py`, `datsc/register.py`). |
| R5 | Honest validation: fixed epochs, final-EMA weights, out-of-fold log loss and AUROC, leave-pseudo-site-out diagnostics; temperature never below 1. |
| R6 | Data hygiene on Kaggle: private datasets, no raw scans as notebook output, delete after the competition (accepted prize-eligibility risk, see `COUNCIL_VERDICT.md`). |

## Architecture (run 3)

```
NIfTI --datsc/io.py--> 2 mm RAS volume --datsc/volume.py--> head mask, p75 box 96x96x72
    --datsc/register.py--> SimpleITK similarity+affine to the symmetric study template (artifacts/template.npz)
                           NCC QC (CoM fallback), reference-region normalisation (SBR+1 units)
    --> arms: 3D GroupNorm ResNet (datsc/models_v3.py)        on the 64x64x48 resize
              torchvision EfficientNet-B0 / V2-S 2.5D          on 3 x 8 mm axial slabs at z=33.5 (datsc/data_v3.py)
              registered-ROI features + logistic regression    (datsc/features_v3.py, scripts/gate_v3.py)
    --> scripts/fit_stack_v3.py: weighted-logit average, temperature (site-fold pool, floor 1.0), prior mix --> manifest.json
    --> main_v3.py + datsc/infer_v3.py (packed as main.py by scripts/pack_v3.py)
```

| Component | Files |
|---|---|
| Caches | `scripts/cache_volumes.py` (CoM boxes), `scripts/build_template.py`, `scripts/register_cache.py` (registered), `scripts/pseudo_sites.py` (site labels and folds) |
| Training | `datsc/train_v3.py`, `scripts/train_v3.py` (fold -1 = full-data model) |
| Test-time augmentation | `InputSpec.variants` in `datsc/train_v3.py` (z-shift x flip), shared by the trainer, `scripts/reoof_v3.py` and inference |
| Kaggle notebook | generated by `kaggle/gen_run3_inject.py`; synced by `kaggle/push_cells.py`; zip transfer by `kaggle/split_zip_cell.py` + `scripts/join_parts.py`; DrivenData upload by `kaggle/gen_submit.py` |
| Legacy run-2 path (kept for the submitted zip) | `main.py`, `datsc/preprocess.py`, `datsc/model.py`, `datsc/train.py`, `datsc/infer.py` |

## Stack

Python 3.12, numpy / scipy / nibabel / SimpleITK / scikit-learn, PyTorch + torchvision, pytest. Training on Kaggle T4 x2 driven through Playwright. Inference in the DrivenData runtime (torch 2.12, timm, MONAI, SimpleITK available).
