Created 2026-09-06 by reverse-engineering the repository state at commit `9e029c8`. Depth: minimal.

## Problem
DrivenData #311: classify 3D DaT-SPECT NIfTI brain volumes as normal / abnormal (`is_pathologic` probability), scored by log loss on a hidden multi-centre test set. Code-execution competition: a `submission.zip` with `main.py` runs offline (1x A100, 3 h, no internet). Deadline 2026-09-16 23:59 UTC. Full rules: `DAT_PARKINSONS_CHALLENGE.md`.

## Requirements (baseline)
- R1 `main.py` must always leave a valid `submission.csv` (uid, is_pathologic) — stage-wise writes, prior first, hard `os._exit(0)`.
- R2 Every test scan processed independently; no pseudo-labelling; no batch statistics across test samples.
- R3 Only public, commercial-use external weights (torchvision ImageNet BSD-3 accepted; DINOv3/NC excluded); disclose.
- R4 Same preprocessing code path in training and inference (`datsc/volume.py` + `datsc/register.py`).
- R5 Honest validation: fixed epochs + final-EMA weights, OOF log loss AND AUROC, leave-pseudo-site-out diagnostics; temperature never < 1.
- R6 Data hygiene on Kaggle: private datasets, no raw scans as notebook output, delete after the competition (accepted prize-eligibility risk, see memory/COUNCIL_VERDICT.md).

## Architecture (current)
- `datsc/io.py` NIfTI load (RAS) + 2 mm resample -> `datsc/volume.py` head mask, p75 box (96x96x72) -> `datsc/register.py` SimpleITK similarity+affine to a symmetric study template (`artifacts/template.npz`), NCC QC, reference-region normalisation.
- Cache: `cache_v3/` (CoM boxes), `cache_v4/` (registered) as memmaps; `scripts/cache_volumes.py`, `scripts/build_template.py`, `scripts/register_cache.py`, `scripts/pseudo_sites.py`.
- Models (`datsc/models_v3.py`): GroupNorm 3D ResNet; torchvision 2D backbones on axial slabs (`datsc/data_v3.py`); registered-ROI LR (`datsc/features_v3.py`, `scripts/gate_v3.py`).
- Training `datsc/train_v3.py` / `scripts/train_v3.py`; combiner `scripts/fit_stack_v3.py` -> `manifest.json`; packer `scripts/pack_v3.py`; inference `main_v3.py` + `datsc/infer_v3.py`.
- Kaggle notebook `dat-parkinsons-train` generated by `kaggle/gen_run3_inject.py`; datasets `dat-parkinsons-challenge-data`, `dat-parkinsons-cache-v4`.
- Legacy run-2 path kept for the submitted zip: `main.py`, `datsc/preprocess.py`, `datsc/model.py`, `datsc/train.py`, `datsc/infer.py`.
